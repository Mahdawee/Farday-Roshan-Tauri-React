# راهنمای کامل: اجرای پروژه و Forward Port در VS Code

> این راهنما برای سیستم **مدیریت شرکت فردای روشن** (PHP + MySQL) نوشته شده است.
> اگر جایی گیر کردید، اول صفحه `doctor.php` را باز کنید — خودِ سیستم می‌گوید مشکل کجاست.

---

## ۰) اول این را بدانید: کِی به Forward Port نیاز دارید؟

| حالتی که پروژه اجرا می‌شود | Forward Port لازم است؟ | آدرس نهایی |
|---|---|---|
| روی **همان کمپیوتر** شما (XAMPP/WAMP، یا `php -S localhost:8080`) | ❌ **نه** — مستقیم در مرورگر باز کنید | `http://localhost:8080` |
| داخل **GitHub Codespaces** | ✅ بلی | `https://8080-xxxx.app.github.dev` |
| با **VS Code Remote – SSH** روی سرور دیگر | ✅ بلی | `http://localhost:8080` (روی کمپیوتر خودتان) |
| داخل **Dev Container / Docker** | ✅ بلی | `http://localhost:8080` |
| داخل **WSL** (ویندوز) | ✅ معمولاً خودکار | `http://localhost:8080` |

**نکته مهم:** اگر پروژه را روی کمپیوتر خودتان اجرا می‌کنید و «PORTS» را باز می‌کنید ولی خالی است —
این کاملاً طبیعی است! فوروارد پورت فقط وقتی معنا دارد که کد در محیط دور (Remote) اجرا شود.

---

## ۱) حالت الف: اجرا روی کمپیوتر خودتان (ویندوز) — ساده‌ترین راه

### ۱-۱) XAMPP نصب کنید
1. `XAMPP` را از سایت رسمی دانلود و نصب کنید (فقط یک بار به انترنت نیاز است).
2. **XAMPP Control Panel** را باز کنید → **Apache** را Start کنید (و اگر می‌خواهید از phpMyAdmin استفاده کنید، **MySQL** را هم Start کنید).
3. پروژه را داخل `C:\xampp\htdocs\farday\` کاپی کنید (کل پوشه، از جمله پوشه `app`).

### ۱-۲) دیتابیس را بسازید
1. در مرورگر باز کنید: `http://localhost/farday/install.php`
2. معلومات را همان‌طور بگذارید (سرور `127.0.0.1`، کاربر `root`، رمز **خالی**) → **شروع نصب**.
3. اگر می‌خواهید آزمایش کنید، تیک «معلومات نمونه» را بگذارید.
4. ورود: `http://localhost/farday/login.php` → `admin` / `admin123`

> در این حالت **هیچ کاری با VS Code Ports ندارید**. فقط مرورگر را باز کنید.

### ۱-۳) اگر می‌خواهید از داخل VS Code اجرا کنید (بدون Apache)
```powershell
# در ترمینال VS Code، داخل پوشه پروژه:
php -S localhost:8080 -t .
# سپس در مرورگر:  http://localhost:8080/install.php
```
اگر `php` شناخته نشد، مسیر آن را اضافه کنید:
```powershell
set PATH=C:\xampp\php;%PATH%
php -v
```
یا در VS Code: `Ctrl+Shift+P` → `Preferences: Open User Settings (JSON)` و اضافه کنید:
```json
{
  "php.validate.executablePath": "C:\\xampp\\php\\php.exe",
  "terminal.integrated.env.windows": { "PATH": "C:\\xampp\\php;${env:PATH}" }
}
```

## ۲) حالت ب: VS Code + Dev Container (سریع‌ترین راه حرفه‌ای)

فایل‌های آماده در پروژه موجود است: `.devcontainer/devcontainer.json` و `docker-compose.yml`.

**پیش‌نیاز:** Docker Desktop نصب و روشن باشد + افزونه **Dev Containers** در VS Code.

1. پروژه را در VS Code باز کنید.
2. `Ctrl+Shift+P` → **Dev Containers: Reopen in Container**
3. منتظر بمانید؛ خودش این کارها را می‌کند:
   - PHP 8.3 + افزونه‌های `pdo_mysql` را آماده می‌کند،
   - یک MariaDB می‌سازد (کاربر `root`، رمز `root`، دیتابیس `farday_roshan`)،
   - فایل `config.local.php` را با آدرس `db` (نام سرویس دیتابیس) می‌سازد،
   - جداول و معلومات اولیه را می‌سازد،
   - سرور PHP را روی `0.0.0.0:8080` استارت می‌کند.
4. در VS Code تب **PORTS** را باز کنید (کنار TERMINAL) → پورت **8080** خودش ظاهر می‌شود → روی آیکن 🌐 کلیک کنید.

> **مهم:** دیتابیس در این حالت `db` است، نه `127.0.0.1`. اگر خودتان دستی نصب می‌کنید، در
> `config.local.php` بنویسید: `'db_host' => 'db'`.

## ۳) حالت ج: GitHub Codespaces

1. در صفحه ریپازیتوری گیت‌هاب: دکمه سبز **Code** → تب **Codespaces** → **Create codespace on main**.
2. بعد از باز شدن، در ترمینال Codespaces اجرا کنید:
   ```bash
   bash start.sh
   ```
   (یا: `php -S 0.0.0.0:8080 -t .`)
3. در پایین/کنار VS Code، پیام **«Your application running on port 8080 is available»** می‌آید →
   دکمه **Open in Browser** را بزنید.
4. اگر پیام را ندیدید: تب **PORTS** → **Forward a Port** → عدد `8080` را وارد کنید → Enter →
   روی آیکن 🌐 کلیک کنید.
5. اگر آدرس باز شد ولی صفحه خطای دیتابیس داد:
   `https://<نام>-8080.app.github.dev/install.php` را باز کنید و نصب را کامل کنید
   (معلومات دیتابیس Codespaces را از تب **Ports/Secrets** یا از `mysql -h 127.0.0.1 -u root` بگیرید؛
   ساده‌ترین راه: `bash .devcontainer/setup.sh` را هم اجرا کنید).
6. **Visibility** پورت را روی **Private** بگذارید (راست‌کلیک روی پورت → Port Visibility).
   اگر Public بگذارید، همه دنیا می‌توانند به سیستم شما وارد شوند.

## ۴) آموزش دقیق کار با تب PORTS در VS Code

1. منوی **View → Terminal** (یا `Ctrl+J`) را باز کنید تا پنل پایین ظاهر شود.
2. بالای پنل، بین تب‌های **PROBLEMS | OUTPUT | TERMINAL | PORTS** → روی **PORTS** کلیک کنید.
   - اگر تب را نمی‌بینید: `Ctrl+Shift+P` → **Ports: Focus on Ports View**.
3. دکمه **Forward a Port** (آیکن `+`) را بزنید و پورت را وارد کنید: `8080` → Enter.
4. ردیفی ساخته می‌شود:
   - **Port**: 8080
   - **Forwarded Address**: آدرس قابل کلیک → روی آیکن 🌐 (Open in Browser) کلیک کنید.
5. راست‌کلیک روی همان ردیف:
   - **Copy Local Address** — برای کاپی آدرس،
   - **Port Visibility → Private/Public** — (فقط در Codespaces)،
   - **Stop Forwarding Port** — برای بستن پورت.
6. پورت‌های فوروارد‌شده ذخیره می‌شوند و بار بعدی خودکار برمی‌گردند
   (تنظیم `remote.restoreForwardedPorts`).

## ۵) چرا «نمیشه»؟ — جدول عیب‌یابی

| نشانه / خطا | علت | راه حل |
|---|---|---|
| تب PORTS خالی است / پیام «No forwarded ports» | سرور PHP استارت نشده (یا کرش کرده) | در ترمینال `php -S 0.0.0.0:8080 -t .` را اجرا کنید؛ خطای آن را بخوانید |
| `php: command not found` | PHP نصب نیست / در PATH نیست | XAMPP/Laragon نصب کنید یا مسیر `C:\xampp\php` را به PATH اضافه کنید |
| `Failed to listen on 127.0.0.1:8080 (Address already in use)` | پورت ۸۰۸۰ مصروف است (یا سرور قبلی هنوز اجراست) | `bash start.sh 8090` (پورت دیگر) یا از تب PORTS سرور قبلی را ببندید. در ویندوز: `netstat -ano \| findstr :8080` و `taskkill /F /PID <عدد>` |
| مرورگر «ERR_CONNECTION_REFUSED» | سرور روی `127.0.0.1` اجرا شده ولی درخواست از بیرون/کانتینر می‌آید | سرور را روی **همه** آدرس‌ها اجرا کنید: `php -S 0.0.0.0:8080 -t .` |
| صفحه باز می‌شود ولی روی «ورود» کلیک می‌کنم دوباره صفحه ورود می‌آید | کوکی‌ها کار نمی‌کنند (آدرس/پروکسی نامتعارف) یا سشن ذخیره نمی‌شود | ۱) آدرس را از همان تب PORTS باز کنید (نه با IP دستی). ۲) `doctor.php` را ببینید — ردیف «سشن» باید سبز باشد. ۳) پوشه ذخیره سشن (`session.save_path`) قابل نوشتن باشد |
| خطای «اتصال به دیتابیس برقرار نشد» | MySQL استارت نیست، دیتابیس ساخته نشده، یا آدرس دیتابیس اشتباه است | `doctor.php` را باز کنید؛ در XAMPP دکمه Start مقابل MySQL؛ اگر Dev Container هستید host را `db` بگذارید |
| بعد از هر صفحه به `install.php` می‌رود | جداول ساخته نشده (جدول `settings` وجود ندارد) | یک بار `install.php` را باز کنید و «شروع نصب» را بزنید |
| فارسی/دری به شکل `????` دیده می‌شود | کدگذاری دیتابیس یا فایل اشتباه است | پروژه با `utf8mb4` ساخته شده؛ مطمئن شوید فایل‌ها را با UTF-8 ذخیره کرده‌اید و در MySQL کالیشن `utf8mb4_unicode_ci` است |
| عدد/تاریخ اشتباه نشان می‌دهد | تقویم یا ساعت سرور اشتباه است | در سیستم: «تنظیمات» → تقویم (شمسی/میلادی). ساعت کمپیوتر و `date.timezone` در `php.ini` (مثلاً `Asia/Kabul`) را درست کنید |
| تغییرات فایل دیده نمی‌شود | حافظه نهی (Cache) یا سرور در پوشه اشتباه اجرا شده | `Ctrl+F5` در مرورگر، و مطمئن شوید `-t .` در پوشه پروژه اجرا شده (`pwd` / `cd`) |
| می‌خواهم از کمپیوتر دیگری در شبکه استفاده کنم | فایروال یا آدرس اشتباه | آدرس `http://<IP-کمپیوتر-سرور>:8080` و در ویندوز اجازه دسترسی فایروال به `php.exe` را بدهید. امن‌تر: از Apache/XAMPP در شبکه داخلی استفاده کنید |

## ۶) میان‌برهای آماده در پروژه

| فایل | کار |
|---|---|
| `start.sh` | استارت سریع سرور روی `0.0.0.0:8080` (لینوکس/مک/WSL/Codespaces) — پورت دیگر: `bash start.sh 8090` |
| `install_cli.php` | نصب/بروزرسانی دیتابیس از خط فرمان: `php install_cli.php --demo` |
| `backup_cli.php` | پشتیبان‌گیری از خط فرمان: `php backup_cli.php` — فهرست فایل‌ها: `php backup_cli.php --list` |
| `start.bat` | همان کار در ویندوز (دوبار کلیک کنید؛ مسیر XAMPP/Laragon را خودش پیدا می‌کند) |
| `doctor.php` | بررسی خودکار سیستم: PHP، افزونه‌ها، دیتابیس، جداول، سشن، پورت — با راه‌حل فارسی |
| `install.php` | ساخت دیتابیس، جداول و معلومات اولیه |
| `.vscode/tasks.json` | تسک‌های آماده: `Ctrl+Shift+B` → «شروع سیستم» و «نصب دیتابیس» و «بررسی سلامت» |
| `.vscode/settings.json` | فوروارد خودکار پورت ۸۰۸۰ و باز شدن مرورگر |
| `.devcontainer/` | محیط آماده PHP 8.3 + MariaDB برای Dev Container / Codespaces |

### اجرای تسک‌های VS Code
1. `Ctrl+Shift+P` → **Tasks: Run Task** → یکی از:
   - «۱) نصب / بروزرسانی دیتابیس»
   - «۲) شروع سیستم (سرور PHP) — فوروارد پورت 8080»
   - «۳) بررسی سلامت سیستم (doctor.php)»
   - «۴) ساخت پشتیبان دیتابیس»
   - «۵) باز کردن سیستم در مرورگر»
2. بعد از اجرای تسک دوم، تب **PORTS** را باز کنید → پورت 8080 → Open in Browser.

### معادل خط فرمانی همان تسک‌ها
```bash
php install_cli.php --demo        # نصب دیتابیس + معلومات نمونه (بدون مرورگر)
php -S 0.0.0.0:8080 -t .          # اجرای سیستم
php doctor.php                    # بررسی سلامت (خروجی ۰ = سالم، خطا = تعداد مشکل)
php backup_cli.php                # پشتیبان در پوشه backups/
php backup_cli.php --list         # فهرست پشتیبان‌های موجود
```
> در ویندوز همین دستورها کار می‌کنند، فقط جای `php` مسیر کامل بگذارید:
> `C:\xampp\php\php.exe -S 0.0.0.0:8080 -t .`
> یا یک فایل `start.bat` را دوبار کلیک کنید.

## ۷) امنیت (مهم)

1. **هرگز پورت ۳۳۰۶ (دیتابیس) را فوروارد نکنید.** فقط ۸۰۸۰ را فوروارد کنید.
2. اگر پورت را Public کردید، حتماً اول:
   - رمز کاربر `admin` را از «کاربران سیستم» عوض کنید،
   - معلومات نمونه را پاک کنید («پشتیبان‌گیری» → یا حذف ردیف‌ها).
3. برای استفاده واقعی شرکت، سیستم را فقط در **شبکه داخلی (LAN)** بالا بیاورید؛ نیازی به اینترنت ندارد.
4. هر هفته از «پشتیبان‌گیری» فایل `.sql` بگیرید و روی فلش کاپی کنید.

## ۸) چک‌لیست خلاصه (چاپ کنید و کنار کمپیوتر بگذارید)

- [ ] PHP نصب است (`php -v` جواب می‌دهد)
- [ ] MySQL/MariaDB روشن است (در XAMPP دکمه Start سبز است)
- [ ] فایل `config.local.php` درست است (یا از `install.php` ساخته شده)
- [ ] `install.php` یک بار اجرا شده و پیام «نصب با موفقیت انجام شد» آمده
- [ ] `doctor.php` همه ردیف‌ها **سبز** است
- [ ] سرور با `php -S 0.0.0.0:8080 -t .` اجرا شده
- [ ] در VS Code تب **PORTS** → پورت **8080** → **Open in Browser**
- [ ] ورود با `admin` / `admin123` موفق است و رمز عوض شده

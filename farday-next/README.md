# فردای روشن — پروژهٔ مستقل نسخهٔ جدید

**وضعیت: بررسی و طراحی، نه برنامهٔ نصب‌پذیر و نه نسخهٔ آمادهٔ استفاده.** این پوشه جدا از PHP ریشه و نمونهٔ فعلی `desktop/` است. هیچ‌کدام تغییر یا حذف نشده‌اند. هدف، ساخت نسخهٔ جدید با React/TypeScript، Tauri 2، Rust/SQLx و دیتابیس متناسب با شیوهٔ واقعی استفاده است؛ نه صرفاً بازسازی ظاهر.

## نتیجهٔ اصلی بررسی

1. نسخهٔ PHP مرجع رفتار و داده است، اما در چند مورد خودش رفتار متناقض یا خطرناک دارد. «عین نسخه» باید با سناریو و نتیجهٔ مورد انتظار تعریف شود؛ کپی کورکورانهٔ یک خطای مالی درست نیست.
2. نمونهٔ فعلی `desktop/` ارزش فنی و آزمون دارد، اما کامل نیست: ورود و مجوز در فرمان‌های واقعی فعال نیست؛ داده‌های PHP وارد نمی‌شوند؛ و دخل دستی آن هم‌ارز دخل قدیم نیست. اجزای آن فقط پس از بررسی و آزمون به پروژهٔ جدید منتقل می‌شوند، نه به شکل کپی کامل و بی‌قید.
3. SQLite برای برنامهٔ محلی روی یک دستگاه مناسب است؛ **چند دستگاه هم‌زمان با فایل مشترک SQLite** راهکار مطمئن جایگزین سرویس مرکزی نیست. شبکه و هم‌زمانی از تصمیم‌های باز و اثرگذار معماری‌اند.
4. اطلاعات قدیمی در MySQL/MariaDB است. فایل پشتیبان SQL قدیم مستقیماً پشتیبان SQLite نیست. انتقال به ابزار اختصاصی، نسخهٔ آزمایشی، کنترل مغایرت و تأیید نیاز دارد.
5. اطلاعات واقعی، قالب رسمی، امنیت، نتایج حسابداری، چاپ بومی و نصب‌کنندهٔ امضاشده بدون آزمون و تأیید مربوط، آماده اعلام نمی‌شوند.

## دامنه و محدودیت این بررسی

بررسی بر اساس کد مخزن در commit مبنا `0bfb8a5431bb2a90f68510b4b3bdb1876b0e4989`، فایل‌های PHP، schema و seed و نمونهٔ `desktop/` است. در این محیط PHP/MySQL و Rust محلی در دسترس نبودند؛ **نسخهٔ PHP با پایگاه واقعی یا نمونه اجرا نشده** و هیچ خروجی واقعی با نسخهٔ جدید تطبیق نشده است. رفتار واقعی نصب‌های قدیمی ممکن است به خاطر نسخهٔ schema، داده‌ها یا تغییرات نصب‌شده متفاوت باشد. باید با پایگاه آزمایشی و سناریوهای ثبت‌شده اعتبارسنجی شود.
